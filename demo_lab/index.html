why-agent — Case Lab

Every AI claim, checked against its evidence. Sources — cards, commits, check runs, receipts, web pages, reviewer models — make claims about a work item. One deterministic reconciler groups them by aspect and returns CORROBORATED, PARTIAL, CONFLICTED, or NO EVIDENCE. Model lanes (NVIDIA Nemotron on Nebius Token Factory) and a Tavily live-evidence lane contribute claims and advisory verdicts — never the verdict. A model narration is machine-checked against the evidence; values that do not literally appear fail the check.

Labels, honestly: every case below is RECORDED — the lane verdicts, costs, and narration flags are from real Token Factory runs on 2026-10-28. The claims are planted fixtures (synthetic work items), built so the correct verdict is known in advance: an adversarial corpus with planted truth, scored in the repo's benchmark/. The deterministic gate scored 14/14 with zero false approvals; the lanes did not — their misses are shown on the cases where they happened.
