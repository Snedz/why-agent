## The honest reading

deep costs ~13× fast per call and buys real accuracy (12 vs 8 agreements; 9 vs 6 corpus-correct). deep falsely approved 1 time(s) and returned 1 unparseable verdict(s). fast falsely approved 2 time(s) and returned 0 unparseable verdict(s). Routing consequence: **fast for cheap first-pass claims triage, deep on escalation, neither as a gate** — the deterministic reconciler, which costs nothing and scored 14/14, decides.

## What this ledger does not contain

- **Narration cost.** The harness does not meter the narration call (the standard tier — nvidia/nemotron-3-super-120b-a12b), so every total here is a reviewer-lane total, not a run total. In the runs above the narration check FAILED 13 time(s) and the failures are recorded in the results files. Metering the narration call is a recorded harness fix.
- **Latency.** Per-call latency is not recorded by the harness, so this ledger publishes no latency percentile: there is no median because none was measured. The only latency facts on record are qualitative (tiers ~1s warm; one ~3-minute cold-load stall).
